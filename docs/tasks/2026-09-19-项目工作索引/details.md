# 项目工作索引与按需上下文详情

## 目标与验收
完整需求以 [方案](../../designs/2026-09-19-项目工作索引与按需上下文详细方案.md) 为准。承接 [项目推进](../../topics/项目推进.md#当前现状) 登记的本阶段事项的 A/B/C 全部施工范围（原开放事项已随验收完成移入现状）。
用户指定本会话只做简单验证，完整验收在其它会话按方案第 16 节执行。本轮不迁移历史、不发布、不改变角色切片算法、check 与 init 的实现。

## 探索结果
相关入口：仓根 `bin/worklog.mjs` 与 `src/context.mjs`。CLI 原布尔开关声明未参与解析，无参直接列任务；现有角色切片与一层必读可复用。init 整目录导出，check 已检查普通链接，无需新增框架或依赖。
已有文档是设计基线与使用契约，没有持续维护全局现状的合理章节，本轮按方案新建 `docs/topics/项目推进.md`。工作区原有 docs/README 改动与两份未跟踪方案/审查文件，沿现有内容更新导航与方案状态，保留审查文件。

## 共同约束
使用用户最新施工授权，主会话直接执行，不使用子代理。零运行依赖，保留任务阶段与单元字段。任务执行进度只在 state；证据在本文件，主题与索引按影响更新。完整验收不在本会话执行。

## 当前设计
方案版本：r4
按方案三批执行，详细规定按各 T 单元的必读定位，不复制整篇。todo 存在时保留原文，只有路径缺失回退；显式 list 复用 listTasks。所有参数组合在 runContext 统一校验，CLI 负责解析和传递布尔开关。全局现状落点为项目推进，示例在现有 title-search 项目中补索引与主题。
待决定：无。
