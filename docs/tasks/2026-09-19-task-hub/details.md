# 改造详情

## 目标与验收
交付独立 Skill 与共享格式的完整工具包。验证角色提取、明确失败、断链报告、初始化不覆盖。通过独立模型施工演练及临时包消费冒烟；最终用户验收另行进行。

## 探索结果
旧入口和 src 包含大量命令、多版配置迁移、三件套和收口门禁；旧 Skill 依赖初始化产物。新方案不兼容旧约定。旧文档保留到 docs/history，不作为新产品说明。

## 共同约束
仅当前分支，保护确认方案。白名单模型执行；无运行依赖、无自动模型调度、无消费 CI。两版共享章节及局部编号。施工自检不同最终验收。

## 当前设计
方案版本：r1
CLI 为 init [目录]、context [任务] [--role explore|design|implement|accept] [--unit T1]、check [路径]。init 默认导出 .agents/skills/worklog；默认 check 排除 docs/history，显式路径可检查历史。

## T1 Skill 与使用文档
### 目标与验收
独立目录可用，渐进加载，内部引用可达，提供真实可施工示例。
最低验证：检查 Skill 元数据、内部引用与示例。
### 方案与范围
写 skills、examples、README.md、docs/README.md、docs/usage.md：入口、角色说明、模板和样例，不依赖 CLI 初始化。格式协议需要改变时回交。
### 依赖与必读
无。
### 当前结果
Skill 入口、五份按角色说明、两个模板、标题搜索演练样例及使用文档已完成；执行者运行 quick_validate.py 成功、内部引用检查通过，样例已有功能 7 项自检通过，待施工需求保留预置失败测试。证据与未验证项见 [交付证据](references/交付证据.md#t1-skill-与使用文档)。

## 发现与经验
历史材料退出默认阅读与检查范围，避免旧规则干扰新产品。

不增加项目级配置系统：默认使用当前项目的 docs；其他文档位置由 check 显式路径处理，符合最小实现范围。
