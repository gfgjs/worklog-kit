# 改造详情

## 目标与验收
交付独立 Skill 与共享格式的完整工具包。验证角色提取、明确失败、断链报告、初始化不覆盖。通过独立模型施工演练及临时包消费冒烟；最终用户验收另行进行。

## 探索结果
旧入口和 src 包含大量命令、多版配置迁移、三件套和收口门禁；旧 Skill 依赖初始化产物。新方案不兼容旧约定。旧文档保留到 docs/history，不作为新产品说明。

## 共同约束
仅当前分支，保护确认方案。白名单模型执行；无运行依赖、无自动模型调度、无消费 CI。两版共享章节及局部编号。施工自检不同最终验收。

## 当前设计
方案版本：r1
CLI 为 init [目录]、context [任务] [--role explore|design|implement|accept] [--unit T1]、check [路径]。init 默认导出 .agents/skills/worklog；默认 check 排除 docs/history，显式路径可检查历史。

## 执行结果
T1：Skill 入口、五份按角色说明、两个模板、标题搜索演练样例及使用文档已完成。执行者运行 quick_validate.py 成功，内部引用检查通过；样例已有功能 7 项自检通过，待施工需求保留预置失败测试。

T3 接续演练：独立 commandcode/deepseek-deepseek-v4.1-flash（High）仅得到临时项目、Skill 与“接续 T2”的请求，完成查询归一化。T2 的 4 项测试和 T1 的 7 项测试通过，CLI 输出正确，任务记录保持待验收。主会话审查关键 diff，并比对验收测试哈希一致，未放宽期望。仓内样例仍保留待施工状态，演练在临时副本进行。该小型样例不能证明复杂项目普遍适用，也未测实际 token 账单。

T2：init/context/check 与 4 个共享解析／路径模块已实现，运行期零依赖。旧命令、配置迁移、门禁引擎及对应分发文件已退役；维护者 CI 改为新测试和现行文档检查，不向消费项目注入 CI。

执行子代理报告的实际验证：bin/src/test 的语法检查通过；npm test 的 50 项测试通过、0 失败；默认 docs 检查 5 个文件通过，显式当前仓根检查 17 个文件通过；显式历史检查报告 5 处旧断链并返回问题状态。历史断链保留为历史限制，不修复已退役材料。

真实包消费：子代理 npm pack 后在临时消费目录安装本次 tgz，验证 init、任务列表、普通接续、四种角色材料和 check 均成功；重复初始化跳过相同文件，本地定制冲突保持原内容；旧命令返回输入错误。未安装或升级第三方运行依赖，未发布新版本。

T3 整合：旧资料集中到 docs/history，已确认当前方案仍在 docs/designs。README 和使用说明按实际帮助更新，提供源码运行方式、语法支持范围及两版边界。主会话依据子代理结果整合，按用户要求没有重跑整套测试。

未验证：远端 GitHub CI、非当前本地环境的实跑、复杂任务的长期多模型成功率、真实 token 账单，以及完整探索—多轮设计的跨模型行为演练。已完成的独立演练只覆盖小型任务从确认方案接续施工。用户最终验收未执行。所有结果以本分支当前实现为范围，不代表已发布版本支持这些能力。

## 发现与经验
历史材料退出默认阅读与检查范围，避免旧规则干扰新产品。

不增加项目级配置系统：默认使用当前项目的 docs；其他文档位置由 check 显式路径处理，符合最小实现范围。
