## 当前设计
方案版本：r3
- state 三节和检查字段保持，进度表只留状态、缺口和单元指针。日常依次保存必要证据、更新单元当前结果、更新变化的 state 字段；只在项目现状或选择改变时维护主题和 todo。撤下过期的等待、派发或验收指令。
- details 共享部分为目标与验收、按需探索结果、共同约束、当前设计；单元为四个三级标题：目标与验收、方案与范围、依赖与必读、当前结果。通用回交/回传规则在角色说明中，只将特有要求写进单元。当前结果按验收条件写结论、适用版本/环境、证据和缺口，不复述实现全文、不逐轮追加。
- 取消全局执行结果正文。原始过程与旧结果放已有报告或按需 references/，以普通链接保留；有效失败保留当前缺口指针，已解决失败明确归为历史。长期产品说明提升到现行文档后只引用。
- 无 role 仍输出 state 三节；explore/design 保持按共享章节读取，探索只保留当前有效发现。implement 必须指定 unit，输出共享约束、当前设计与该单元四组材料。accept 支持可选 unit：指定时输出目标、共享约束、当前设计及该单元全文；不指定时为整体验收，输出上述共享材料和全部单元的目标与验收、依赖与必读、当前结果，并给方案定位。验收者须按相关条件补读方案、差异与真实证据；摘要不能单独证明通过。
- 一层必读从实际所选片段收集，不展开普通历史链接；同文件 # 锚点与带文件路径锚点都支持，完整区间包含才去重。不引入递归依赖图、语义自动裁剪或第二套现行格式。
- context/check 共用四项单元定义与结构判断；施工/待验收/完成要求可用单元，探索/设计允许未决。旧八项格式在需单元材料时给迁移提示，不静默遗漏旧结果。体积提示观察 state、共享章节、每个单元及其当前结果；保持非阻断、UTF-8 字节计量，不代表 token。
- 本仓库五个任务均迁移到单一现行格式，完成任务只调整布局、保留状态与历史；外部旧记录提供人工迁移说明，普通历史 Markdown 仍可读取。修复受影响的活链接，不保留两套正文或永久旧格式执行分支。
