# 精简记录与接续详情

## 目标与验收
用户根据三个真实会话的 token 分析同意优化。降低重复记录、全文重读与临时状态回写，保留授权、有效约束、失败证据和版本适用范围。自检要求：既有测试、文档检查、Skill 校验与样例角色提取通过；实际 token 净收益仍需后续匹配对照，不据文本变短宣称已节省固定比例。

## 探索结果
样本：`01a0c758-fe52-7bc2-8ead-5226e0c00041`、`01a0c7c0-b81a-72c1-98ec-2ae9e07d856d`、`01a0c844-2791-7b60-b29d-5aec1d9e9da1`。记录写入相关响应占输出约 44.4%、35.5%、23.0%，包含推理和混合工作，不能全归因于文档。后续会话确有接续；主要可改进点是长篇追加、短暂等待落盘和必读扩张。现有 `context` 已支持角色章节、一层必读与去重。

## 共同约束
沿用两份任务文件、既有字段、四角色读集与 CLI；不新增配置、长度门禁或自动裁剪。历史失败与适用版本继续可查，相关证据仍需实际核实。
