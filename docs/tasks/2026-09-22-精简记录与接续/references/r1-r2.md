# 精简记录与接续详情

## 目标与验收
用户根据三个真实会话的 token 分析同意优化。降低重复记录、全文重读与临时状态回写，保留授权、有效约束、失败证据和版本适用范围。自检要求：既有测试、文档检查、Skill 校验与样例角色提取通过；实际 token 净收益仍需后续匹配对照，不据文本变短宣称已节省固定比例。

## 探索结果
样本：`01a0c758-fe52-7bc2-8ead-5226e0c00041`、`01a0c7c0-b81a-72c1-98ec-2ae9e07d856d`、`01a0c844-2791-7b60-b29d-5aec1d9e9da1`。记录写入相关响应占输出约 44.4%、35.5%、23.0%，包含推理和混合工作，不能全归因于文档。后续会话确有接续；主要可改进点是长篇追加、短暂等待落盘和必读扩张。现有 `context` 已支持角色章节、一层必读与去重。

2026-09-26 补充长会话观察：文档读写为主的请求约占输出 11.5%，其中回写占大头；出现整篇 details 读取和截断，state 行数变化小但字节数显著增长。该归类不是可直接省去的 token，也没有同质量的无 worklog 对照。用户据此授权 r2 优化。

## 共同约束
沿用两份任务文件、既有字段、四角色读集与 CLI；不新增配置、长度门禁或自动裁剪。历史失败与适用版本继续可查，相关证据仍需实际核实。

## T2 记录归属与体积反馈
### 目标与验收
减少重复叙述与不相关单元读取；体积提示能定位长字段，不改变正文、引用或退出码。样例保持 T1 已实现、T2 未实现的事实。
### 依赖与前提
r1 的任务协议与角色提取已存在；用户已授权本轮优化，发布与外部项目迁移不在范围内。
### 必读材料
无额外必读；现行写作与工具契约见 [使用说明](../../../usage.md)。
### 修改范围
仓根 `skills/worklog/`、`src/context.mjs`、`src/check.mjs`、CLI 帮助、相关测试、使用说明、README、标题搜索样例文档和本任务索引。
### 实现路径
原位修改规则与模板；context 给所选正文 UTF-8 字节摘要，check 独立报告体积提示。提醒阈值为 state 4096 B、当前节单字段值含续行 1024 B、共同约束/当前设计各 8192 B、执行结果 16384 B；不新增配置或参数，不截断正文。
### 最低验证
完整测试、文档与 Skill 校验、样例四角色提取；核实中文按 UTF-8 字节统计、提示不失败、原错误不被掩盖、授权与证据完整。比较样例原始正文体积；字节下降不等同 token 净节省。
### 回交条件
需要自动删减证据、改变验收标准、增加持久状态或扩展外部项目时回交；普通实现修复自行处理。
### 回传要求
实现、验证、样例对比及实际 token 收益尚未验证的限制。
