## 当前设计
方案版本：r6
- state 三节和检查字段保持，进度表只留状态、缺口和单元指针。日常依次保存必要证据、更新单元当前结果、更新变化的 state 字段；只在项目现状或选择改变时维护主题和 todo。撤下过期的等待、派发或验收指令。
- details 共享部分为目标与验收、按需探索结果、共同约束、当前设计；单元为四个三级标题：目标与验收、方案与范围、依赖与必读、当前结果。通用回交/回传规则在角色说明中，只将特有要求写进单元。当前结果按验收条件写结论、适用版本/环境、证据和缺口，不复述实现全文、不逐轮追加。
- 取消全局执行结果正文。原始过程与旧结果放已有报告或按需 references/，以普通链接保留；有效失败保留当前缺口指针，已解决失败明确归为历史。长期产品说明提升到现行文档后只引用。
- 无 role/unit 输出 state 三节；无 role 且指定 unit 时仅补读该单元及其一层必读，供复用已有共享材料时使用。explore/design 按共享章节读取；implement 必须指定 unit，输出共享约束、当前设计与该单元四组材料。accept 指定 unit 时输出目标、共享约束、当前设计及该单元全文；整体验收输出共享材料和全部单元的目标与验收、依赖与必读、当前结果，并给方案定位。验收者按条件补读方案、差异与真实证据。
- 一层必读从实际所选片段收集，不展开普通历史链接；同文件 # 锚点与带文件路径锚点都支持，完整区间包含才去重。不引入递归依赖图、语义自动裁剪或第二套现行格式。
- context/check 共用四项单元定义与结构判断；施工/待验收/完成要求可用单元，探索/设计允许未决。体积提示保持非阻断、UTF-8 字节计量，不代表 token。历史材料继续可达，工具不自动裁剪或迁移。

默认复用当前上下文中已读或亲自写入的材料；新消息、继续执行、切换角色或模型本身不触发重读。所需原文缺失、已知外部修改或具体版本冲突时，只补受影响章节，不例行检查文件或版本。角色读集列出需要掌握的材料；查询进度缺少状态时只取 state，已有共享材料时只补新单元，需要完整角色材料时用现有 --role，部分缺失只补相关章节。手工读取在一次调用内按标题边界输出所需章节，示例保留围栏正文及单元子节。公共章节只保存跨单元约定，单元之间用精确依赖连接。
