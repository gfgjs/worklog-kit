# 项目推进

本文件是项目全局现状的正文落点；单个任务的执行进度以其 state 为准。

## 当前现状

### 当前总目标
交付个人开发者可独立使用的 worklog Skill 与轻量 CLI，用简短索引选择工作、按角色读取任务材料，支持跨会话接续。本阶段的工作索引与全局视图已施工、通过完整验收并随 0.2.1 发布。

### 阶段成果与关键缺口
已有 init/context/check 和四角色任务协议。工作索引入口、显式任务枚举、主题治理与模板已施工，完整验收通过（场景覆盖索引、CLI 分支、角色读集、补读、事项流转、全局视图、打包交接，证据见 [验收记录](../tasks/2026-09-19-项目工作索引/details.md#验收记录)）。0.2.1 已发布 npm；先前任务的待验收状态保留，不据本索引推定完成。

### 跨主题依赖
索引与主题治理沿用两份任务文件；单元结构与验收读集已按本轮方案调整，一层必读与普通 Markdown 保持。命令契约见 [使用说明](../usage.md)，治理正文见 [治理规则](../../skills/worklog/references/governance.md)。目前无需另建产品专题正文。

### 记录与接续优化
r1/r2 的记录纪律与体积反馈已有历史自检。用户批准的 r3 整体改造已落实到规范、CLI 与本仓库记录：单元内维护当前结果、历史证据按需读取、角色与单元共同决定读集。新能力尚未发布，验证与验收状态集中见[任务记录](../tasks/2026-09-22-精简记录与接续/state.md)；实际 token 净收益仍待同任务对照。
