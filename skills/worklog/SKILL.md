# worklog — 任务中枢与文档治理

用户要求规划、接续、按方案施工、换模型交接，或维护项目文档落点时使用本 Skill。一次性问答、无需接续的小改做完即可，不建档。

## 记录位置

任务默认落在项目的 `docs/tasks/<日期-可读名称>/`：

| 文件 | 装什么 | 权威范围 |
|---|---|---|
| `state.md` | 目标摘要、阶段、执行边界、进度表、下一步与阅读 | **当前进度只在这里** |
| `details.md` | 目标与验收、探索结果、共同约束、当前设计、各施工单元、执行结果、发现与经验 | 细节与证据 |

目录名 = `YYYY-MM-DD-可读名称`；T1、T2 等编号只在该任务内有效。文件存在不代表获准施工，也不代表设计已确认。

## 阶段与状态

`阶段：探索 | 设计 | 施工 | 待验收 | 完成 | 已取消` 写在 state.md 的「当前」节。暂停与阻塞用同节的说明字段表达，不另造阶段组合。单元状态用 `未开始 | 进行中 | 待处理 | 已自检`。已自检不等于已验收；取消写「已取消」和原因，不冒充完成。

## 角色路由

先读 state.md 定位阶段与下一步，再按角色读**一份**参考；不要一次加载全部参考。

| 角色 | 何时用 | 读什么 |
|---|---|---|
| 探索 | 目标清楚，需要摸清现状 | state + details 的「目标与验收」，加已存在的「共同约束」「探索结果」→ [references/exploration.md](references/exploration.md) |
| 设计 | 需要定方案、拆单元、改接口 | state + 「目标与验收」「探索结果」「共同约束」「当前设计」→ [references/design.md](references/design.md) |
| 施工 | 按已定方案实现指定单元 | state + 「共同约束」「当前设计」+ 该单元 + 单元内显式必读 → [references/implementation.md](references/implementation.md) |
| 验收 | 检查交付是否达标 | state + 「目标与验收」「当前设计」「执行结果」→ [references/acceptance.md](references/acceptance.md) |

涉及文档落点、有效性、断链或知识沉淀时加读 [references/governance.md](references/governance.md)。新建或修复任务文件结构时，用 [templates/state.md](templates/state.md) 与 [templates/details.md](templates/details.md) 作骨架。

## 共同规则

- **授权决定施工。** state.md 的「执行边界」写清本次允许做什么。处于只讨论阶段时，任务文件存在或方案完整都不构成施工许可；方案写入文件也不自动等于获准执行。
- **格式标记不等于批准。** 章节、必读、单元齐全只说明材料完整，工具不判断授权。以用户最新指令为准；指令与记录冲突时按用户执行并回写记录。
- **当前进度只在 state.md。** details.md 不维护第二份进度表；先写详情与证据，再更新 state 摘要。
- **必读用独立行标注：** `必读：[名称](相对当前文件的路径.md#锚点)`，一行一个，只标 Markdown 片段。源码与测试给路径指针（注明相对哪个根），不把实现全文抄进任务文件。
- **无项写「无」，未决写「待定」。** 不留占位符，不把推测写成用户决定；探索与设计阶段允许「待定」与尚无施工单元，不要求填满整套模板。
- **重大偏差回交。** 接口或行为与方案前提不符、需扩大范围、需新增依赖、验收矛盾，或连续尝试没有新增有效信息时，停止受影响单元并回传期望、实际、证据与需要的决定。
- **改动即维护文档。** 行为变了就更新受影响的现行说明，避免复制第二份规范；长期结论提升到主题文档，任务详情只留摘要与指针。

## 工具（可选，非必需）

项目若提供 `worklog-kit`：`context` 按角色抽取材料，`check` 检查结构与引用问题，`init` 把本 Skill 导出到指定目录。命令契约见该项目的使用说明。没有工具时按上面的读取规则手工读文件；本 Skill 目录单独复制后不依赖任何 CLI。

## 最低验证

单元完成后按风险做最低充分验证（语法检查、局部运行、相关测试、实际行为），把证据写进 details.md 的「执行结果」并更新 state.md。环境不支持的验证写「未验证」和原因；不得改验收标准来制造通过。
